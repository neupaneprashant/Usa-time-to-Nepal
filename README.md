# Kathmandu Work Shifts

Tuesday / Thursday / Friday shifts (8:00 AM – 5:00 PM US Central, Ruston LA)
converted to Nepal time for November and December 2026.

- `index.html` — open in a browser. Shows the next shift with a countdown, every
  shift in Nepal time, and buttons to add shifts to Google Calendar or Outlook.
- `nepal-work-shifts.ics` — all 26 shifts as calendar events (30-minute reminder).
  Import into Apple Calendar, Outlook, or Google Calendar.
